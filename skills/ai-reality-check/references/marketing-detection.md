# 营销夸大识别 (Marketing Hype Detection)

目的：逐项比对"待核查表述"与"实际证据"，识别社交媒体常见的夸大与误导手法。输出 `marketing_analysis`。

## 常见夸大/误导模式

1. **标题党（Title Inflation）**
   - 标题断言远强于内容证据。例：标题"AI 一键生成完整游戏"，内容仅是生成了一个 30 秒占位 Demo。
   - 标志：标题含绝对词（完全/一键/彻底/零基础），内容含大量前提。

2. **选择性展示（Cherry-picking）**
   - 只展示成功案例，隐藏失败率、前置条件、人工干预。
   - 标志：无失败案例、无成本披露、无复现步骤。

3. **隐藏前提（Hidden Precondition）**
   - "无需编程也能开发软件"实际需：购买订阅、学习提示词、人工调试、外包收尾。
   - 标志：结果描述与"所需投入"严重不对称。

4. **Demo 伪装产品（Demo-as-Product）**
   - 把理想条件下的演示片段当作稳定可用的成品宣传。
   - 标志：无公开可用版本、无可复现环境、仅视频展示。

5. **个例代表普遍（Survivorship）**
   - 一个成功者代表"所有人都能复制"。
   - 标志：无基数、无对照、无失败样本。

6. **无依据数字（Unfounded Numbers）**
   - "日入十万""效率提升 1000%""省下 90% 成本"，无可靠来源或方法论。
   - 标志：数字精确但无出处、无统计口径。

7. **混淆相关与因果（Correlation≠Causation）**
   - "用了 AI 所以赚到钱"，无对照实验，忽略市场/运气/其他投入。
   - 标志：单一变量归因、无对照组。

8. **恐惧营销（Fear-mongering）**
   - "再不学 AI 就被淘汰""程序员三年消失"，用焦虑替代证据。
   - 标志：时间断言 + 无数据支撑 + 情绪驱动。

## 识别流程
1. 列出内容中的**关键断言**（来自 core_claims）。
2. 逐条对比已有证据：
   - 证据支持且边界一致 → 非夸大。
   - 证据显示需额外条件/人工 → 标记"隐藏前提"。
   - 证据显示仅 Demo/个例 → 标记对应模式。
   - 数字无出处 → 标记"无依据数字"。
3. 在 `marketing_analysis` 中**逐条指出**：模式名 + 原文引用 + 实际证据落差。

## 输出规范
- 每项夸大：指明模式、引用原文、说明落差、给出修正后更公允的表述。
- 若未发现明显夸大：明确写"未发现明显夸大"，不强行找问题。
- 区分"内容方夸大"与"标题方（平台/搬运）夸大"，若可判断。

## 注意
- 识别夸大不等于判定"内容为假"。一项技术可能真实但被夸大包装 → verdict 用 `misleading` 或 `partially_verified`。
- 保持公允：若内容确实如实展示了能力，明确肯定，不为了"找问题"而挑刺。
