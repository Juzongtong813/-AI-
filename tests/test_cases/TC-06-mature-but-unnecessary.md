# TC-06 某项技术成熟，但普通用户没有必要使用

- **模式类别**：相关性误用（非夸大，但需校准）
- **模拟平台**：科普 / 测评
- **模拟内容**：
  - "这个 AI 修图工具已达专业级，人人都该用。"
  - 技术层面确实成熟（verified）。
- **输入主张**：
  - C1：该工具修图能力达专业级（已验证，真实）。
  - C2：普通用户"都该用"（适用性判断，非技术事实）。
- **期望调查结论**：
  - C1 → `verified`（技术真实，避免误判真实能力）。
  - C2 → 不适用事实 verdict；在"个人目标分析"中结合用户需求判断，且不得反向污染 C1。
- **期望识别的夸大模式**：无明显夸大；重点是公允肯定真实技术，避免过度 skeptic。
- **验证要点**：本案例检验 Skill 是否**不会**把真实技术误判为虚假；识别夸大 ≠ 判定虚假。
