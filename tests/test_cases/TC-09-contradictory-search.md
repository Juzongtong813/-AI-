# TC-09 搜索结果互相矛盾

- **模式类别**：证据矛盾（Contradiction）
- **模拟平台**：混合信源
- **模拟内容**：
  - 关于某 AI 医疗诊断工具：一方（厂商+赞助媒体）称准确率 95%；另一方（独立评测+论文）称在真实场景中显著下降且有误诊风险。
- **输入主张**：
  - C1：该工具在受控环境下准确率高（可能为真）。
  - C2：该工具在真实临床场景可靠可用（矛盾）。
- **期望调查结论**：
  - C1 → `partially_verified`（受控环境证据）。
  - C2 → `contradicts_evidence` 或 `unverified`：双方证据质量需比较（独立评测/论文权重更高），并列矛盾点。
- **期望识别的夸大模式**：混淆受控环境与真实场景。
- **验证要点**：证据矛盾时必须并列双方，不强行下结论；按来源可靠性定主导。
