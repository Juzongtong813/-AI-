# TC-05 AI 赚钱宣传，没有可靠收入证据

- **模式类别**：无依据数字（Unfounded Numbers） / 个例代表普遍
- **模拟平台**：小红书 / 短视频
- **模拟内容**：
  - "用 AI 做自媒体，我一个月赚了 8 万，你也行！"
  - 仅展示收入截图（无第三方佐证、无口径、无成本披露）。
- **输入主张**：
  - C1：作者声称自己用 AI 赚到钱（个例，自述）。
  - C2：普通观众"也行"（可复制性，需统计证据）。
- **期望调查结论**：
  - C1 → `unverified`（单方截图，无法独立核实）。
  - C2 → `unverified` 或 `misleading`：无基数、无对照、无失败样本。
- **期望识别的夸大模式**：无依据数字、个例代表普遍。
- **验证要点**：要求可靠收入证据（平台数据/税务/第三方复盘）；个例不得支撑普遍结论。
