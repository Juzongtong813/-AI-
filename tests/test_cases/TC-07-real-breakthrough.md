# TC-07 某项技术确实构成重要突破

- **模式类别**：真实突破（校准正向判断）
- **模拟平台**：论文 / 官方 + 多独立实测
- **模拟内容**：
  - 某新模型在权威 benchmark 上取得显著提升，多篇独立复测确认。
- **输入主张**：
  - C1：该模型在指定 benchmark 上显著提升（可验证）。
  - C2：该提升对实际应用场景有实质价值（需应用侧证据）。
- **期望调查结论**：
  - C1 → `verified`（官方 + 多独立复测一致）。
  - C2 → `partially_verified`：benchmark 提升 ≠ 通用能力跃迁，需应用验证。
- **期望识别的夸大模式**：无明显夸大；重点是给出公允的"已验证"结论，不被过度怀疑污染。
- **验证要点**：当官方与多独立证据一致时，应明确给出 `verified` 与 `high` 置信度，而非一律保守。
