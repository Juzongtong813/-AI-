# TC-04 GitHub 项目开源，但无法正常运行

- **模式类别**：Demo 伪装产品 / 个例
- **模拟平台**：GitHub + 自媒体推文
- **模拟内容**：
  - 自媒体："我开源了一个 AI 项目，star 破千，clone 就能用！"
  - 实际仓库：缺少依赖锁版本、文档缺失、issues 中多人报"跑不起来"。
- **输入主张**：
  - C1：该项目已开源且获较多 star（可验证，多为真）。
  - C2：普通用户 clone 后即可正常运行使用（需验证可复现性）。
- **期望调查结论**：
  - C1 → `verified`（star 数可查）。
  - C2 → `partially_verified` 或 `unverified`：issues 中复现失败普遍，缺少环境说明。
- **期望识别的夸大模式**：把"star 多"偷换为"开箱即用"；忽略可运行性门槛。
- **验证要点**：主动查 issues / discussions 中的运行反馈，不因 star 数判定可用性。
