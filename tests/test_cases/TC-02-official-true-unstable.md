# TC-02 官方宣传真实，但实际效果不稳定

- **模式类别**：选择性展示（Cherry-picking）
- **模拟平台**：厂商发布会 / 官方博客
- **模拟内容**：
  - 官方宣称某视频生成模型"可生成电影级画面"。
  - 演示均为精选片段。
- **输入主张**：
  - C1：该模型能生成高质量视频（官方演示为真）。
  - C2：该模型在**常规输入**下稳定产出电影级画面（需独立实测验证）。
- **期望调查结论**：
  - C1 → `verified`（官方演示可见）。
  - C2 → `partially_verified`：独立实测常报告不稳定、易崩坏、需大量抽卡/人工筛选。
- **期望识别的夸大模式**：选择性展示（只展示成功案例）。
- **验证要点**：务必检索独立实测与用户反馈，不能仅凭官方演示判定"稳定可用"。
