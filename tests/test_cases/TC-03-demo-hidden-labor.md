# TC-03 Demo 真实，但隐藏了大量人工操作

- **模式类别**：隐藏前提（Hidden Precondition） / Demo 伪装产品
- **模拟平台**：带货自媒体
- **模拟内容**：
  - 视频："我用这个 AI 工具 10 分钟做完了一个 App，全程没写一行代码。"
  - 实际：演示前已准备好设计稿、素材包、账号体系，并剪掉了大量调试/重试片段。
- **输入主张**：
  - C1：该工具能在无代码情况下生成可运行 App（部分真实）。
  - C2：普通用户"10 分钟、零准备"即可产出可发布 App（含隐藏前提）。
- **期望调查结论**：
  - C1 → `partially_verified`（需前提与人工）。
  - C2 → `misleading`：隐藏了准备与调试成本。
- **期望识别的夸大模式**：隐藏前提、Demo 伪装产品。
- **验证要点**：追问"演示前后的真实投入"，把隐藏前提拆为子主张单独验证。
