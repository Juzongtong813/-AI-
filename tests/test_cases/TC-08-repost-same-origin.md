# TC-08 多个媒体转载同一个原始消息

- **模式类别**：共同出处（Co-origin） / 转载
- **模拟平台**：多家新闻/自媒体
- **模拟内容**：
  - A 媒体、B 媒体、C 自媒体都报道"某 AI 公司获巨额融资、技术领先"。
  - 三者均转引自同一厂商通稿 / 同一原始公告。
- **输入主张**：
  - C1：某 AI 公司获巨额融资（需查原始公告）。
  - C2："技术领先"被广泛认可（多家媒体报道 ≠ 独立认可）。
- **期望调查结论**：
  - C1 → 以**原始公告**为单一独立证据计数，而非 3 家。
  - C2 → `unverified`：通稿被转载不构成独立第三方认可。
- **期望识别的夸大模式**：共同出处导致"证据数量"虚高。
- **验证要点**：必须使用 `scripts/dedup_sources.py` 或人工判定同源；在独立性说明中合并计数。
