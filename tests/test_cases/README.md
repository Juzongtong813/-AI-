# AI Reality Check 测试案例集 (Test Cases)

本目录是 Skill 行为评估用的**真实调查测试场景**。每个案例描述一类在社交媒体上常见的 AI 信息失真模式，给出模拟内容、期望的调查结论与应识别的夸大模式。

这些案例用于：
1. 评估 Skill 在不同失真模式下的判断质量（人工或 Agent 复核）。
2. 作为回归基线，验证 Skill 规范/工作流未被破坏。
3. 其中部分案例可由 Agent 用真实网络搜索**现场执行**（见 `examples/` 的真实演示）。

使用方式：
- 人工复核：阅读案例，按 `skills/ai-reality-check/workflows/` 执行，比对"期望结论"。
- 自动评估：可让 Agent 对每个案例跑一遍，将产出报告与"期望结论"对照打分。

> 注意：案例中的"模拟内容"用于说明模式，不代表对任何真实个人或产品的指控；涉及真实主体时以实际证据为准。
