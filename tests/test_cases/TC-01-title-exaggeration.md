# TC-01 技术真实，但标题夸大

- **模式类别**：标题党（Title Inflation）
- **模拟平台**：抖音 / YouTube 标题
- **模拟内容**：
  - 标题："AI 彻底颠覆编程，程序员要失业了！"
  - 正文/视频：演示用 AI 补全了一个简单函数的单元测试，并生成了一段 CRUD 代码。
- **输入主张（拆解后）**：
  - C1：AI 能生成可用的代码片段（真实，可验证）。
  - C2：AI 让"程序员"这一职业整体失业（夸张，需劳动力市场证据）。
- **期望调查结论**：
  - C1 → `verified`（有广泛实测支撑）。
  - C2 → `unverified` 或 `misleading`：标题断言 >> 内容证据；职业影响需宏观数据，个例演示不能支撑"失业"。
- **期望识别的夸大模式**：标题党、恐惧营销。
- **验证要点**：必须区分"工具辅助编码"与"职业消亡"两个不同层级的断言，不被标题带节奏。
